🌍 About the Project

AccessAble is a web-based accessibility discovery platform focused on making accessibility information easier to discover and explore.

The platform allows users to browse different public places and explore information about accessibility features such as ramps, lifts, step-free access, accessible toilets, and parking.

AccessAble aims to make accessibility information easier to understand through a clean interface, search functionality, filters, place details, and a reporting interface.

🎯 Problem Statement

Finding accessibility information about public places can be challenging.

People may have difficulty discovering whether a location provides wheelchair access, ramps, elevators, accessible toilets, or other accessibility facilities.

AccessAble aims to address this information-discovery problem through a simple and user-friendly platform.

🚀 Project Objectives

- Make accessibility information easier to explore.
- Provide a simple place discovery experience.
- Organize accessibility features through filters.
- Provide a structured interface for accessibility reports.
- Encourage better awareness of accessibility in public spaces.

⚙️ How It Works

1. Open the AccessAble website.
2. Navigate to the Explore section.
3. Browse available places.
4. Search for locations or apply category filters.
5. Select accessibility features to filter results.
6. Open a place to view its accessibility breakdown.
7. Use the reporting interface to submit information within the prototype.

⚠️ Important Disclaimer

AccessAble is currently a prototype that uses illustrative demo data.

The displayed locations, accessibility statuses, statistics, and reports are sample information and are not verified real-world accessibility records.

Reports submitted through the current prototype are stored locally on the device if localStorage is used. They are not automatically shared with other users or uploaded to a central server.

Users should not rely on demo information for real-world accessibility planning.
