# ♿ AccessAble – Accessibility Discovery Platform

**Making Accessibility Easier to Discover.**

AccessAble is a web-based platform designed to help people discover places based on their accessibility features and explore accessibility information.

## 🌐 Live Demo
[Visit AccessAble](https://accessable-nine.vercel.app)

## ✨ Key Features
- 🔍 Search for places
- ♿ Explore accessibility information
- 🏢 View accessibility features of places
- 📝 Submit accessibility reports
- 📱 Responsive user interface
- 🎯 Simple and user-friendly design

## 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript
- Git & GitHub
- Vercel
